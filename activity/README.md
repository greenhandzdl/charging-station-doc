![故障报修处理活动图](img/activity_repair.svg)

## 活动流程

1. 用户/管理员发现故障，提交报修单
2. 系统自动将对应充电桩状态设为"故障"
3. 并行执行：管理员查看未处理报修并分配维修人员，系统通知维修人员
4. 维修人员接收任务，执行维修操作
5. 维修完成，更新报修单状态为"已处理"
6. 系统将充电桩状态恢复为"空闲"
