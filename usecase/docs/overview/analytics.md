# 统计与可视化用例

**参与者：** 系统、管理员、最高管理者

**核心需求：** 生成按站点、时间区间的充电次数与收入汇总；统计充电桩状态比例（空闲/使用中/故障）。

## 主场景

1. 系统按日/周/月汇总充电记录与收入，生成简要报表数据。
2. 管理员或最高管理者在界面请求报表，系统返回表格或图表数据供前端绘制（柱状图、饼图）。

## 非功能性需求

- 支持导出 CSV。
- 报表计算可异步执行以避免阻塞主流程。
- 敏感统计数据（收入汇总）仅限最高管理者访问。
