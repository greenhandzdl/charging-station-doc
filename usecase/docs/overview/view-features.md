# 视图与便捷功能

**考核要求对应：** 模块5 — 视图与便捷功能

**参与者：** 用户、管理员、维修人员、最高管理者

## 充电记录快捷视图

1. 用户或管理员在主界面查看快捷视图表格，直接显示用户姓名、车牌号、充电桩ID、充电量、费用。
2. 数据来自视图或复杂查询，无需进入多级菜单即可快速浏览。

## 充电桩状态快捷查询

1. 用户或管理员输入充电站名称。
2. 系统返回该充电站下所有充电桩的ID与当前状态（空闲/使用中/故障）。

## 安全说明

- **充电记录快捷视图**：已认证用户仅可查看本人的充电记录；管理员可查看全部记录。
- **充电桩状态快捷查询**：已认证用户均可查询，结果仅含站点名称和桩编号/状态，不包含地址等敏感信息。未授权用户不可访问该功能。
