# 前端用例与交互契约

本文件为前端交付级说明，涵盖关键用例、与后端的接口契约要点、安全与测试要求。

## 主要用例

注册/登录、充值、启动充电、结束充电与结算、查看历史记录、提交报修、管理员桩管理、用户权限管理。

## 参与者界面

| 角色 | 可访问界面 |
|------|-----------|
| 未授权用户 | 注册/登录 |
| 用户 | 充电操作、充值、个人记录查看、报修提交 |
| 维修人员 | 充电操作、充值、个人记录查看、报修提交与处理 |
| 管理员 | 充电站/充电桩管理、用户管理、报修管理、权限管理 |
| 最高管理者 | 全部管理界面、统计报表、权限管理 |

## 与后端契约要点

- 使用 HTTPS，敏感操作由后端处理或加密传输。
- 登录使用短期凭证（HttpOnly Cookie 或安全存储 JWT），Token 过期后刷新。
- 支付流程：前端调用 `POST /api/v1/payments/create` 获取支付参数，支付完成后由后端回调并确认。
- 管理界面根据角色权限动态显示/隐藏功能入口。

## 安全与测试要点

- 凭证不在前端明文持久化；严格输入校验与输出转义（防 XSS）。
- CSRF 防护（SameSite/CSRF token）。
- 前端根据角色隐藏非授权操作（但后端仍做权限校验，前端不可信任）。
- 单元测试、集成测试与 E2E（Playwright / Cypress / Flutter integration tests），在 CI 中执行关键 E2E 流程。
