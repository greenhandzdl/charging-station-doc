# 基础信息管理用例

充电站、充电桩及用户数据的创建、查询、修改与删除操作，仅限管理员及以上角色访问。

**参与者：** 管理员、最高管理者

**前置条件：** 操作者已登录并具有管理权限。

## 管理充电站

1. 操作者进入充电站管理界面，系统展示充电站列表。
2. 操作者点击新增，填写充电站名称、地址、充电桩数量与运营状态并提交。
3. 系统校验输入（名称非空、桩数量为非负整数），保存记录并返回成功提示。
4. 操作者可对已有充电站进行修改或删除操作。

## 管理充电桩

1. 操作者选择充电站后进入充电桩管理界面。
2. 操作者新增/编辑充电桩，填写充电桩编号、类型、状态。
3. 系统校验充电桩编号唯一性，保存并返回成功提示。

## 管理用户

1. 操作者查看用户列表，可搜索、筛选用户。
2. 操作者可编辑用户基本信息或调整用户角色权限（权限变更需记录审计日志）。
3. 权限提升操作仅限管理员及以上角色执行。

## 备选场景

- 充电桩编号冲突：系统提示并拒绝保存。
- 数据库异常：系统提示错误并记录日志，操作回滚。

## 后置条件

数据在数据库中保持一致性并可被后续流程使用。
