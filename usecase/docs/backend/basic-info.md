# 基础信息管理用例

用例名称：充电站 / 充电桩 / 用户 管理

参与者：`管理员`

前置条件：管理员已登录系统并具有管理权限。

主场景（典型步骤）：

1. 管理员进入“充电站信息管理”界面，系统展示充电站列表。
2. 管理员点击“新增”，填写充电站名称、地址、充电桩数量与运营状态并提交。
3. 系统校验输入（例如名称非空、桩数量为非负整数），保存记录并返回成功提示。
4. 管理员可选择对已有充电站进行修改或删除操作。

备选场景：

- 若添加或修改的充电桩 ID 存在冲突，系统提示并拒绝保存。
- 若数据库连接异常，系统提示错误并记录日志，操作回滚。

后置条件：充电站/充电桩/用户信息在数据库中保持一致性并可被后续流程使用。
