# 充电流程用例

用例：启动充电 / 结束充电

参与者：用户、管理员、支付网关、系统

前置条件：用户已登录，充电桩在系统中存在且未被占用。

主场景（启动充电）：

1. 用户选择充电桩并发起“启动充电”。
2. 系统校验用户存在、账户余额>=最低余额且充电桩状态为“空闲”。
3. 系统创建充电记录，记录开始时间，并将充电桩状态设为“使用中”。

主场景（结束充电）：

1. 用户或系统触发“结束充电”。
2. 系统记录结束时间，计算充电量与费用。
3. 系统尝试从用户账户扣费；扣费成功则更新充电记录状态为“完成”，并将充电桩状态设为“空闲”。
4. 若扣费失败，则标记为“欠费”，记录异常日志并通知管理员。

备选场景：

- 充电桩在启动时已被占用：返回错误并提示用户选择其他桩。
- 余额不足：阻止启动并提示充值（或允许管理员介入）。

后置条件：充电记录入库，充电桩状态与用户余额一致。
