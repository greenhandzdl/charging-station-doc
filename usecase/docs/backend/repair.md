# 故障报修用例

**参与者：** 用户、维修人员、管理员

## 提交报修

1. 用户、维修人员或管理员在界面提交报修，填写充电桩 ID 与故障描述。
2. 系统生成报修单并将对应充电桩状态设为"故障"。

## 处理报修

1. 管理员查看未处理报修单，分配处理人员给维修人员（或由管理员直接处理）。
2. 维修人员接收报修任务后开始维修。
3. 完成维修后，操作者更新报修单状态为"已处理"，并将充电桩状态恢复为"空闲"。

## 后置条件

报修单记录入库，充电桩状态恢复，记录处理人及时间。
