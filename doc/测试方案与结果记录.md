## 1. 测试概述

### 1.1 测试范围

本测试覆盖系统六大功能模块的完整功能链，包括：

1. **基础信息管理** — 用户/充电站/充电桩的 CRUD
2. **充电业务与记录管理** — 启动充电、结束充电、记录查询
3. **支付与故障报修管理** — 充值、支付记录、报修提交/处理
4. **数据统计与可视化分析** — 用户统计、运营分析、使用率分析
5. **视图与便捷功能** — 快捷视图、桩状态查询
6. **简易交互与扩展功能** — 余额校验、自动扣费、欠费处理

完整测试：`登录 → 查桩 → 充值 → 启动充电 → 停止充电 → 自动扣费`

```
# 用户(13800138001) 启动前余额: 50.00
POST /api/v1/charges/start → 启动成功, recordId=xxx
等待 2 秒模拟充电
POST /api/v1/charges/stop  → 停止成功, status=COMPLETED
系统自动计算费用并扣费: 50.00 → 50.00 - fee
充电桩状态: CHARGING → IDLE
```
