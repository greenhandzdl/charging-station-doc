### 题目：基于 Java 的新能源汽车充电站管理与数据分析系统

#### 一、功能需求

##### 1. 基础信息管理模块

1)  **充电站信息管理界面**：提供图形化界面，支持对充电站信息进行增、删、改、查操作。充电站信息包括：名称、位置、充电桩数量、运营状态。添加或修改信息后，需同步更新至数据库。

2)  **充电桩信息管理界面**：提供图形化界面，支持对充电桩信息进行增、删、改、查操作。充电桩信息包括：桩ID、类型（快充/慢充）、状态（空闲/使用中/故障）。充电桩的ID必须唯一且不可重复添加。

3)  **用户信息管理界面**：提供图形化界面，支持对用户信息进行增、删、改、查操作。用户信息包括：姓名、手机号、车牌号、账户余额。手机号需具有唯一性校验，添加或修改时若重复应给出提示。

##### 2. 充电业务与记录管理

1)  **启动充电界面**：用户通过界面输入用户ID和充电桩ID，模拟开始充电。系统需校验用户和充电桩是否存在，充电桩状态是否为"空闲"。校验通过后，创建一条充电记录，记录开始时间（自动获取系统时间），并将对应充电桩状态更新为"使用中"。

2)  **结束充电界面**：通过充电记录ID或用户ID与充电桩ID组合，模拟结束充电。系统自动计算充电量（可模拟固定值或随机值）和费用（例如：充电量
    \*
    1.5元/度），记录结束时间，更新充电记录，并将充电桩状态恢复为"空闲"。

3)  **充电记录查询界面**：以表格形式展示所有充电记录，内容包括：用户姓名、充电桩ID、开始时间、结束时间、充电量、费用。支持按用户ID或充电桩ID进行筛选查询。

##### 3. 支付与故障报修管理

1)  **支付记录界面**：提供支付记录录入功能（模拟用户充电完成后支付），记录支付方式（微信、支付宝、信用卡等）、支付时间、支付金额。同时，界面应能以列表形式展示所有历史支付记录。

2)  **故障报修界面**：用户或管理员可通过该界面提交充电桩故障报修单，记录故障充电桩ID、故障描述、报修时间（自动生成）。报修后，对应充电桩状态应自动变为"故障"。

3)  **故障处理界面**：管理员可通过此界面查看所有"未处理"的报修单，并可将报修单状态更新为"已处理"。处理完成后，对应充电桩的状态应恢复为"空闲"。

##### 4. 数据统计与可视化分析

1)  **用户充电统计界面**：以表格或图表（如柱状图）形式，统计并展示每位用户的累计充电次数和总充电费用。支持按总费用降序排序。

2)  **充电站运营分析界面**：分析并展示以下数据：

    a.  每个充电站的总充电次数和总收入。

    b.  当前处于"故障"状态的充电桩及其所属充电站（以表格形式高亮显示）。

3)  **充电桩使用率分析界面**：通过饼图或柱状图，展示所有充电桩中"空闲"、"使用中"、"故障"三种状态的比例。

##### 5. 视图与便捷功能

1)  **充电记录快捷视图**：在主界面或单独窗口提供一个表格视图（可考虑使用视图或复杂查询实现），直接显示"用户姓名、车牌号、充电桩ID、充电量、费用"信息，方便快速浏览。

2)  **充电桩状态快捷查询**：提供查询入口，输入充电站名称后可实时查看该站所有充电桩的ID和当前状态。

##### 6. 简易交互与扩展功能

1)  **用户账户充值界面**：提供对指定用户ID进行账户余额充值的功能。

2)  **启动充电前置余额校验**：在"启动充电"时，系统需先检查用户账户余额是否不低于预设的最低余额（如10元）。若余额不足，应提示并拒绝启动充电。

3)  **充电完成自动扣费**：在"结束充电"逻辑中，除了更新充电记录和桩状态，还需自动从用户账户余额中扣除本次充电费用。若余额不足扣费，应给出提示并将扣费状态标记为"欠费"（可扩展字段）。

#### 二、成绩评定方法

本课程采用结课设计方式进行考核，旨在培养学生综合运用 Java 知识和 Swing
组件开发以及数据库编程分析解决实际问题的能力，提升学生的编程实践与系统设计水平。学生总成绩依据课程目标要求，从知识掌握、功能实现、设计规范等方面进行综合评定：

##### 1. Java 基础语法与面向对象思想应用（支撑课程目标点 1，本项满分 40 分）

学生需熟练运用 Java
基础语法，包括数据类型、运算符、流程控制语句等，确保程序逻辑正确。深入理解面向对象编程思想，合理设计类与对象，如设计 User 类管理用户信息、Trip 类记录出行数据等，运用封装、继承、多态等特性提高代码的可维护性与扩展性。设计方案需体现对系统功能的全面理解，类与类之间的关系清晰合理。

##### 2. Swing 组件应用与 JDBC 数据库编程（支撑课程目标点 2，本项满分 40 分）

学生要熟练使用 Java Swing
组件创建美观、易用的图形用户界面，实现各功能模块的界面交互。界面布局合理，组件响应事件处理正确。掌握
JDBC
数据库编程技术，实现与数据库的连接、数据的增删改查操作。确保用户信息、出行记录、积分数据等能准确地存储到数据库中，并能正确读取和更新。在数据库操作和界面交互过程中，合理运用异常处理机制，保证程序在数据库连接失败、SQL
语句执行错误、界面操作异常等情况下的稳定性。

##### 3. 系统功能完整性与代码规范性（支撑课程目标点 3，本项满分 20 分）

学生需完成系统所有功能模块的开发，确保各功能在图形界面上能够正常运行，功能逻辑正确。代码编写遵循良好的编程规范，包括合理的变量命名、适当的注释、规范的缩进格式等，提高代码的可读性。程序需具备一定的健壮性，能够处理用户的错误输入，如在输入用户名、密码或出行信息时输入错误格式，系统应给出相应提示并引导用户正确输入。在系统测试方面，需提供简单的测试方案与测试结果记录，验证系统功能的正确性。

**成绩按百分制评定，适当控制成绩优秀的人数比例，一般不高于 20%。**
