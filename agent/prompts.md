# 提示词模板

本文件提供可复用的提示词模板，供 AI 助手在后续交互中直接使用。

---

## 提示词模板 1：完整工作指引（入场提示词）

```
你正在维护充电站管理系统 UML 文档项目。请遵循以下规则：

**根本约束**：`doc/1.Java开发项目实训题目及评分标准.md` 是所有 UML 文档的最根本依据。该文档定义了：
- 六大功能模块：基础信息管理、充电业务与记录管理、支付与故障报修管理、数据统计与可视化分析、视图与便捷功能、简易交互与扩展功能
- 三档评分维度：面向对象设计（40分）、Swing+JDBC（40分）、完整性+规范性（20分）
- 成绩等级描述（60分以下至90-100分的要求）

所有 UML 图、用例描述、数据表设计必须严格覆盖上述模块，并与评分维度对齐。

**AGENTS.md** 提供了执行层面的指引：中文交付、MVP 原则、审核停顿点、渲染流程。

**工作流程**：
1. 修改任何文档前，先阅读 `agent/plan.md` 了解当前进度和待办
2. 如果发现需求冲突或歧义，记录到 `agent/conflicts.md` 并暂停等待用户决断
3. 完成一个阶段后，更新 `agent/plan.md` 的进度状态
4. 在启动类图、数据库设计等非平凡逻辑前，必须先呈现草案并等待用户审核
5. 修改 `.puml` 后立即渲染生成 SVG，并更新所有 Markdown 中的图片引用
6. 交付前检查所有文档是否为中文、无 AI 措辞、引用一致

**文件位置**：
- PlantUML 源：`usecase/docs/{module}/src/`
- SVG 图：`usecase/docs/{module}/img/`
```

## 常用快捷提示词

### 完整性审核
```
逐条对比 `doc/1.Java开发项目实训题目及评分标准.md` 与 `usecase/docs/` 下的所有文档，找出需求遗漏或偏差，输出缺失清单，不要修改文件。
```

### 渲染所有 UML 图
```
运行 `python3 usecase/scripts/render_plantuml.py` 渲染所有 PlantUML 源，并检查生成的 SVG 是否正确。
```

### 更新图片引用
```
检查 `usecase/docs/` 下所有 Markdown 文件中的图片引用路径，确保与对应 `img/` 目录中的 SVG 文件名一致。
```

### 清理 AI 措辞
```
扫描 `usecase/docs/` 下所有 Markdown 文件，查找并移除 AI 助手措辞（"我可以"、"我会"、"建议您"、"如需"、"作为AI"等），改为面向交付的正式说明。
```

### 生成交付清单
```
列出本仓库中所有新增、修改、建议删除的文件（路径+一句话说明），生成交付清单等待用户确认。
```

## 审核触发点

以下场景必须暂停并等待用户审核后才能继续：

1. **画类图前** — 列出核心实体名和每个实体的字段（类型与最小安全要求），暂停
2. **修改数据库设计前** — 展示要改的表结构与理由，暂停
3. **超出 MVP 范围的用例** — 记录为"后续迭代"，不直接实现
4. **涉及文件移动/删除** — 先展示变更清单，暂停
5. **完成一个阶段后** — 展示进度与下一步，暂停
