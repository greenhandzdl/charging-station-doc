# 项目计划与进度

## 项目概况

本项目为充电站管理系统 UML 文档库，核心依据为 `doc/1.Java开发项目实训题目及评分标准.md`，覆盖六大功能模块和三档评分维度。目标是为课程设计学生提供完整、一致的用例文档与 UML 图。
